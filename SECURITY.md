# Security Policy

## Reporting a vulnerability

Don't open a public issue. Report it privately instead: open the [Security tab](https://github.com/jameshuangcoding/guava/security) and click **Report a vulnerability**.

Include what the issue is, how to reproduce it, and what it affects. You'll get a reply within a few days.

## Supported versions

Only the latest version on `main` gets security fixes.
